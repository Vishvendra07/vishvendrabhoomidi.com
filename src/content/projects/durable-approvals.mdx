## The problem

A Temporal reservation workflow that waits for approval, survives worker replacement, and releases work on expiry or cancellation.

## The engineering decision

Store workflow decisions in Temporal history. Deduplicate the simulated side effect with a receipt key, and distinguish business cancellation from process interruption.

## What you can verify

The local Temporal test-server run covers continuation after worker replacement, the approval deadline, cancellation, and the resulting receipts.

[Inspect the recorded evidence](https://github.com/Vishvendra07/durable-approvals/blob/main/evidence/demo.json) · [Read the source and run locally](https://github.com/Vishvendra07/durable-approvals)

## Scope and tradeoffs

Simulated reservation activities and local test infrastructure. The run does not exercise an external reservation provider.

The repository includes setup instructions, automated tests, and a GitHub Actions workflow. Recorded local evidence and current hosted CI are separate signals; the repository shows the latest run status.
