## The problem

A real OCR run on six generated nutrition labels, comparing strict and normalized field extraction.

## The engineering decision

Hold OCR output fixed while comparing parsers. Keep field-level counts so normalization improvements can be attributed and remaining failures inspected.

## What you can verify

Saved OCR output and per-field comparisons accompany six generated label images, including slightly tilted typography. A field regression gate checks the fixture results.

[Inspect the recorded evidence](https://github.com/Vishvendra07/nutrilens-ocr-bench/blob/main/evidence/demo.json) · [Read the source and run locally](https://github.com/Vishvendra07/nutrilens-ocr-bench)

## Scope and tradeoffs

Generated labels form a small controlled set. Results do not estimate population accuracy or reuse the original course project’s assets.

The repository includes setup instructions, automated tests, and a GitHub Actions workflow. Recorded local evidence and current hosted CI are separate signals; the repository shows the latest run status.
