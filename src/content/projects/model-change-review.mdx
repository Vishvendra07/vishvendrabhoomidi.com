## The problem

A comparison of trained word and character TF-IDF classifiers with paired errors, confusion matrices, and abstention thresholds.

## The engineering decision

Evaluate distinct text and show paired predictions. Make routing coverage and the cost of abstention visible alongside classification scores.

## What you can verify

The saved report includes 24 training examples, 21 evaluation examples, two changed stress-case predictions, and threshold-by-threshold routing coverage.

[Inspect the recorded evidence](https://github.com/Vishvendra07/model-change-review/blob/main/evidence/demo.json) · [Read the source and run locally](https://github.com/Vishvendra07/model-change-review)

## Scope and tradeoffs

Small synthetic text data and uncalibrated confidence. The report recommends independent validation before routing customer tickets.

The repository includes setup instructions, automated tests, and a GitHub Actions workflow. Recorded local evidence and current hosted CI are separate signals; the repository shows the latest run status.
