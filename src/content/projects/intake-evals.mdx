## The problem

A 60-case regression harness for intake extraction, corrections, uncertainty, withdrawn requests, and supporting evidence.

## The engineering decision

Score extracted values and evidence separately. Expose wrong, missing, and unsupported fields so a corrected answer cannot hide an unsupported citation.

## What you can verify

Across 60 authored fixtures, exact matches rise from 24 to 60 between the first-mention baseline and the evidence-aware policy. The report retains field scores and individual failures.

[Inspect the recorded evidence](https://github.com/Vishvendra07/intake-evals/blob/main/evidence/comparative-report.json) · [Read the source and run locally](https://github.com/Vishvendra07/intake-evals)

## Scope and tradeoffs

Both extractors are deterministic. These are authored regression cases, not a held-out evaluation of a language model or a general accuracy claim.

The repository includes setup instructions, automated tests, and a GitHub Actions workflow. Recorded local evidence and current hosted CI are separate signals; the repository shows the latest run status.
