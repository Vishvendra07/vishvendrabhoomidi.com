## The problem

A billing-event projection that handles out-of-order arrival and replay using a contiguous event sequence.

## The engineering decision

Build state only through the highest contiguous valid sequence. Enforce provider identity and sequence uniqueness to retain an auditable event history.

## What you can verify

The recorded lifecycle shows a later event arriving first, the missing predecessor arriving afterward, and a processed event being replayed.

[Inspect the recorded evidence](https://github.com/Vishvendra07/subscription-reconciliation-lab/blob/main/evidence/demo.json) · [Read the source and run locally](https://github.com/Vishvendra07/subscription-reconciliation-lab)

## Scope and tradeoffs

One authored lifecycle and fixed currency. No provider charges, payment processing, or production ledger handling.

The repository includes setup instructions, automated tests, and a GitHub Actions workflow. Recorded local evidence and current hosted CI are separate signals; the repository shows the latest run status.
