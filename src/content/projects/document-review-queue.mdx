## The problem

A review queue that combines evidence flags and validation with a versioned human decision.

## The engineering decision

Confidence alone cannot clear an extraction. Record the evidence, validation state, reviewer, and revision with the final decision.

## What you can verify

The saved trace routes an authored extraction to review, records a decision, and rejects a stale second decision while retaining audit entries.

[Inspect the recorded evidence](https://github.com/Vishvendra07/document-review-queue/blob/main/evidence/demo.json) · [Read the source and run locally](https://github.com/Vishvendra07/document-review-queue)

## Scope and tradeoffs

Synthetic OCR observations and a local workflow. The demo does not make real eligibility or payment decisions.

The repository includes setup instructions, automated tests, and a GitHub Actions workflow. Recorded local evidence and current hosted CI are separate signals; the repository shows the latest run status.
