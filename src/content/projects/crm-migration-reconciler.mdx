## The problem

A migration planner that normalizes contact records and surfaces conflicting email and phone matches.

## The engineering decision

Treat conflicting identity signals and duplicate source IDs as review cases. Report planned counts and reasons before any merge can occur.

## What you can verify

The saved reconciliation lists input candidates, ambiguous rows, staged creates, and a rerun that creates no extra records.

[Inspect the recorded evidence](https://github.com/Vishvendra07/crm-migration-reconciler/blob/main/evidence/demo.json) · [Read the source and run locally](https://github.com/Vishvendra07/crm-migration-reconciler)

## Scope and tradeoffs

Authored sandbox contacts and US phone normalization. The planner does not write to an actual CRM.

The repository includes setup instructions, automated tests, and a GitHub Actions workflow. Recorded local evidence and current hosted CI are separate signals; the repository shows the latest run status.
