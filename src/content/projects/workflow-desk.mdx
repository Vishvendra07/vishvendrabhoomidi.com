## The problem

A React case workspace that preserves an operator’s draft when another session saves a newer revision.

## The engineering decision

Treat the persisted revision as a write precondition. Keep the local draft separate from the server record until the operator chooses how to reconcile the conflict.

## What you can verify

The saved browser evidence shows two independent operator sessions editing one case, a stale save, draft recovery, and a successful retry. API and browser tests cover the path.

## Scope and tradeoffs

SQLite makes the demo portable. The fictional operator selector represents demo actors and is not authentication.

The repository includes setup instructions, automated tests, and a GitHub Actions workflow. Recorded local evidence and current hosted CI are separate signals; the repository shows the latest run status.
