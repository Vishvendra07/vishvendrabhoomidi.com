## An edit collides

Two operators open the same case. When one saves, the second still has an unsaved draft against the old revision. The API returns `409` with the current record. The editor shows the server notes, status and owner beside the preserved draft. The second operator can keep the draft for an explicit retry or load the server version.

## Evidence

The API test checks that the rejected write adds zero audit revisions, then verifies one revision for the successful retry. Chrome reproduced the workflow manually. Playwright exercised separate contexts, keyboard activation, persistence after reload, and a compact mobile queue. The project uses seeded users and a local SQLite database.
