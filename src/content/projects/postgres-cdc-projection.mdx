## The problem

A PostgreSQL logical-stream consumer that recovers after a sink commit without acknowledgment and reconciles the resulting view.

## The engineering decision

Commit the projection and watermark together. Acknowledge the source only after that transaction so a restarted consumer can skip already committed history.

## What you can verify

The PostgreSQL 17 trace applies two changes, restarts without acknowledgment, applies zero duplicates, and then processes the next transaction. The final projection matches the source.

## Scope and tradeoffs

A dedicated development database, test_decoding, and a small integer schema. The evidence covers insert, update, delete, and simulated consumer restart.

The repository includes setup instructions, automated tests, and a GitHub Actions workflow. Recorded local evidence and current hosted CI are separate signals; the repository shows the latest run status.
