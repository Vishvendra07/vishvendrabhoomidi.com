## The acknowledgment fails

The service commits an order and its outbox together. A receiver records a synthetic order event, then returns a failure to simulate an unconfirmed delivery. The worker retries the same event ID. The receiver acknowledges the existing receipt and the worker settles the delivery only while its lease is current.

## Evidence

Seven PostgreSQL tests cover atomic enqueue, duplicate submissions, worker claims, stale leases, expiry and duplicate receipt handling. The full Compose demo exercises normal delivery, retry after commit and exhaustion. The measured benchmark belongs to the local workload and is published with raw results.
