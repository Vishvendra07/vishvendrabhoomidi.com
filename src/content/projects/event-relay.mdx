## The problem

A PostgreSQL outbox that retries delivery, coordinates worker leases, and keeps the receiver’s persisted effect idempotent.

## The engineering decision

Commit the order and outbox in one transaction. Claim work with SKIP LOCKED, perform HTTP outside the lock, and reject results from an expired attempt.

## What you can verify

The local HTTP demo covers normal delivery, an acknowledgment failure after receipt commit, and exhaustion before a receipt exists. Seven PostgreSQL tests exercise concurrency and recovery.

[Inspect the recorded evidence](https://github.com/Vishvendra07/event-relay/blob/main/evidence/demo.json) · [Read the source and run locally](https://github.com/Vishvendra07/event-relay)

## Scope and tradeoffs

Synthetic orders, a local Docker host, and a fixed receiver. At-least-once delivery does not establish exactly-once behavior across arbitrary integrations.

The repository includes setup instructions, automated tests, and a GitHub Actions workflow. Recorded local evidence and current hosted CI are separate signals; the repository shows the latest run status.
